  رفع سريع على Render.com (مجاني) — Quick Deployment
═══════════════════════════════════════════════════════════════════════════════

🎯 الخطوات السريعة:

1️⃣  أنشئ حساب GitHub
    👉 https://github.com/signup

2️⃣  رفع الملفات على GitHub
    في Command Prompt:
    
    git init
    git add .
    git commit -m "Invoice Generator"
    git remote add origin https://github.com/YOUR_USERNAME/invoice-generator.git
    git branch -M main
    git push -u origin main

3️⃣  أنشئ حساب Render
    👉 https://render.com
    (استخدم GitHub للدخول)

4️⃣  أنشئ Web Service في Render
    - اضغط "New +" → "Web Service"
    - اختر repository: invoice-generator
    - Build Command: pip install -r requirements.txt
    - Start Command: python run.py

5️⃣  انتظر 5-10 دقائق
    - Render سيبني التطبيق تلقائياً

✅ التطبيق على الإنترنت!

الرابط سيكون:
👉 https://invoice-generator.onrender.com

  مشاكل شائعة

❌ "Application failed to start"
✅ الحل: تحقق من requirements.txt و Procfile

❌ قاعدة البيانات فارغة
✅ الحل: استخدم Render Shell لتهيئة البيانات

❌ الموقع بطيء جداً
✅ السبب: النسخة المجانية توقف التطبيق بعد 15 دقيقة
✅ الحل: ترقِ إلى Plan مدفوعة ($7/شهر)
