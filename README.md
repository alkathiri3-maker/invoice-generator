# 💼 مولّد الفواتير التدريبي للمحاسبين — إتقان

برنامج ويب محلي (Windows) لتوليد **فواتير ضريبية وسندات قبض/صرف عشوائية واقعية**
لتدريب المحاسبين على المراجعة والتدقيق — مع تصدير PDF احترافي ودعم كامل للعربية.

> ⚠ **تعليمي بحت**: كل المخرجات تحمل ختمًا أحمر «نسخة تدريبية» وعبارة
> «نسخة تدريبية - غير صالحة للاستخدام الرسمي». لا يصلح لأي استخدام فعلي.

---

## 🚀 التشغيل

```powershell
# 1) تثبيت المتطلبات (مرة واحدة)
pip install -r requirements.txt

# 2) التشغيل (يفتح المتصفح تلقائيًا)
python run.py
# العنوان: http://127.0.0.1:8788
```

أو بالنقر المزدوج على **`run.bat`**.

- قاعدة البيانات SQLite تُنشأ تلقائيًا في `data/itqan_invoices.db` مع بيانات تجريبية
  (3 شركات، 5 عملاء، 3 مجموعات، 22 صنفًا، قالبان جاهزان).
- لا حاجة لأي إعداد آخر.

## 🔐 بوابة حماية المشرف

- عند أول تشغيل يطلب البرنامج **كلمة مرور المشرف** قبل الوصول إلى أي قسم (أقسام المشرف
  واعتماد الفواتير اليدوية).
- **كلمة المرور الافتراضية: `admin123`** — يُنصح بتغييرها فورًا من «لوحة المشرف» →
  «كلمة مرور بوابة المشرف» (تُخزَّن مُعمّاة PBKDF2 ولا يمكن استرجاعها).
- زر «تسجيل الخروج» في أسفل الشريط الجانبي، والجلسة تبقى سارية حتى إغلاق المتصفح.

## 🛡️ الإعدادات والأمان (شاشة /settings)

- **كلمة سر التحكم في الصلاحيات**: تُخزَّن مُعمّاة (PBKDF2-HMAC-SHA256 بملح عشوائي).
  عند تفعيل الحماية يُطلب كلمة السر قبل **حذف أي بيانات** وقبل **استعادة/حذف النسخ الاحتياطية**،
  وكذلك قبل تغيير مفاتيح الحماية نفسها.
- **النسخ الاحتياطية**: نسخة ZIP تحتوي قاعدة البيانات (لقطة متسقة عبر sqlite3 backup API)
  + الشعارات + المفاتيح + meta.json بالعدّادات. إنشاء/تنزيل/استعادة (من القائمة أو برفع ملف)/حذف،
  مع **نسخة أمان تلقائية قبل كل استعادة**، حد أقصى 30 نسخة، وخيار **نسخة تلقائية يومية** عند بدء التشغيل.
- **مظهر البرنامج**: لون الواجهة (أزرار/بطاقات/جداول بتدرجات مشتقة تلقائيًا)، تدرج الشريط الجانبي،
  وشريط **تنبيه عام** يظهر أعلى كل الشاشات (يُمسح بتركه فارغًا).
- **مظهر المستندات**: اللون الرئيسي ولون الترويسة + **اختيار الخط** (Cairo/Tajawal/Amiri/Noto Kufi/Almarai)
  **وحجمه** — يُحقنان تلقائيًا في كل الفواتير والسندات مهما كان القالب (حتى المخصص)، وشريط التنبيه
  والختم المائي والتذييل.
- **لون المؤسسة**: تغيير لون أي شركة فورًا من الجدول (يظهر في ترويسة فواتيرها).

## ⚙️ إعدادات التوليد

- **الشركة البائعة** و**عميل أو أكثر** (توزيع عشوائي).
- **الفترة**: تاريخ البداية والنهاية — تواريخ عشوائية **تصاعدية**.
- **العدد**: عدد إجمالي محدد أو **متوسط يومي × عدد الأيام**.
- **المبلغ الإجمالي**: صافي أو **شامل الضريبة** — مع **حد أدنى لكل فاتورة**.
- **طريقة الدفع**: نقدي / آجل / تحويل / عشوائي موزون.
- **بذرة عشوائية (Seed)**: نفس البذرة = نفس النتائج تمامًا (قابل لإعادة الإنتاج).
- **QR**: بدون / **مبسط** (TLV وسوم 1-5) / **مرحلة ثانية وهمي** (9 وسوم + هاش XML + توقيع ECDSA
  secp256k1 بمفاتيح تدريبية موقعة ذاتيًا في `data/keys/` — وليست شهادة ZATCA).
- **سندات مرافقة**: سند قبض/صرف لكل فاتورة (نوع محدد أو عشوائي).
- **الترقيم**: بداية وبادئة قابلة للتخصيص، متسلسل مع **فجوات عشوائية (+9 إلى +47)**
  لمحاكاة فواتير ملغاة.

## 🔬 دقة الحسابات (أساس التدقيق)

- كل الحسابات داخلية **بوحدة الهللة (أعداد صحيحة)** — لا أخطاء فاصلة عائمة.
- **الوضع الصافي**: مجموع صافي الفواتير = المبلغ المطلوب **تمامًا**.
- **الوضع الشامل**: مجموع الإجماليات بعد الضريبة = المطلوب **تمامًا بالهللة**
  (إزاحة دقيقة تلقائية لأكبر فاتورة).
- الضريبة 15% تُحسب **على مستوى كل سطر** ثم تُجمع للفاتورة.
- بناء الأصناف (2-5 أسطر): كميات صحيحة ثم سد الفرق
  بـ**صنفين رخيصين بحل صحيح** أو **صنف موازن بكمية كسرية**،
  مع دمج المتكررات وتحقق نهائي: المجموع = الهدف تمامًا.
- **تفقيط عربي كامل** للمبلغ بالحروف (ريالات وهللات).

## 📄 التصدير PDF

- قوالب HTML/CSS احترافية RTL (خط Cairo) — A4 بعلامة مائية حمراء مائلة.
- محرك مزدوج: **WeasyPrint** إن كانت مثبتة، وإلا **Microsoft Edge headless**
  (متوفر افتراضيًا في Windows — لا يحتاج أي تثبيت).
- تصدير: **PDF واحد مجمّع** لكل الدفعة، أو **ملفات منفصلة داخل ZIP**.
- رمز QR يُعرض كصورة داخل المستند مع تنويه تدريبي واضح (حجم 45مم + منطقة هادئة 4 وحدات).

## 🔎 فحص وتحقق الباركود (شاشة /verify)

زر **«🔎 فحص QR»** بجانب أي فاتورة لديه باركود يفتح صفحة الفحص التي تعرض:

- الرمز بحجم كبير + الحمولة Base64 للنسخ.
- جدول الوسوم TLV (1-9) بقيمها وأطوالها.
- **فحوصات تلقائية** بنفس منطق تطبيق ZATCA:
  - الوسم 4/5: المبلغ صحيح (ريالات، بلا فواصل آلاف — تنسيق الهيئة).
  - الوسم 6: هاش SHA-256 = SHA-256 لـ XML الفاتورة (مع زر تنزيل XML).
  - الوسم 7: التوقيع ECDSA secp256k1 يطابق المفتاح العام (وسم 8) — **صحيح رياضيًا** ✅.
  - الوسم 9: شهادة ختم تدريبية موقعة ذاتيًا (معلومات الشهادة والتسلسل).
- **صفحة HTML مستقلة** («🌐 صفحة HTML للتجربة») بنفس الشكل الذي اعتدت عليه،
  لكن بحمولة حقيقية ومدقق secp256k1 يعمل داخل المتصفح (لم يعد يعتمد على بايتات حشو).
- حقل **لصق Base64 ممسوح من الجوال** لفحص أي رمز خارجي.

### لماذا يرفض تطبيق ZATCA الرسمي رمز التدريب؟

سلسلة القبول: الهاش (6) ← التوقيع (7) ← المفتاح (8) ← **شهادة CSID صادرة من الهيئة** (9).
شهادة التدريب موقعة ذاتيًا، فلا يمكن لأي أداة تدريبية تجاوز الشرط الأخير — لذلك رفض
التطبيق الرسمي **متوقع وليس خللًا**. المدقق في التطبيق يثبت صحة الهاش والتوقيع تمامًا
مع إبراز أن الشهادة تدريبية (قسم «الفحوصات» يعرض هذا بوضوح).

|---|---|
| `company` | `name address tax_number cr_number color logo_data_uri` |
| `customer` | `name address tax_number phone` |
| `inv` (فاتورة) | `number date_display time_display payment_type notes lines subtotal_display tax_display total_display total_words qr_img qr_note` |
| `inv.lines[]` | `name code unit quantity_display unit_price_display line_net_display line_tax_display line_gross_display` |
| `rc` (سند) | `number type doc_title date_display time_display amount_display amount_words related_invoice notes` |
| عام | `doc_title watermark_text footer_notice generated_note` |
